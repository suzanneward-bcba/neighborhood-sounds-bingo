# Neighborhood Sounds Bingo

A listening bingo game for children. Print 3×3 picture cards, then play real recorded sounds from the Caller screen. Each card has a QR code that opens the "Find the sound" game so families can practice at home.

Live page: https://suzanneward-bcba.github.io/neighborhood-sounds-bingo/
Find the sound game (QR code target): https://suzanneward-bcba.github.io/neighborhood-sounds-bingo/#find

## Sections
- `#cards`: print cards
- `#caller`: play sounds during a game
- `#practice`: tap pictures to hear sounds
- `#find`: mystery-sound matching game
- `#credits`: sound sources

## Sound credits
Recordings are CC0 (public domain) clips from Freesound, via the ESC-50 dataset by Karol J. Piczak, except one child-laughing clip by OBXJohn (CC BY 3.0). The phone ringtone, train horn, and ball bounce are generated. Full list is on the Sound credits tab.

QR codes are generated with qrcode-generator by Kazuhiko Arase (MIT License).
